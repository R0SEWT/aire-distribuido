# Capturas del andamiaje de la UI (TB2)

Tomadas el 21/11/2026 con Chrome contra el Docker Compose del repo (API, dos nodos, MongoDB, Redis y el servicio
`web`), con usuarios de prueba creados para esa corrida. Son del andamiaje: las pantallas todavía muestran su
marcador de «en construcción». Las capturas del informe se toman cuando las pantallas estén.

| Archivo | Qué muestra |
|---|---|
| `ingreso.png`, `ingreso-proyector.png` | La pantalla de ingreso, en modo normal y en modo proyector |
| `armazon-usuario.png` | El armazón con un usuario común: el menú no tiene Entrenamiento ni Clúster |
| `armazon-admin.png`, `armazon-admin-proyector.png` | El armazón con un administrador, en los dos modos |
| `componentes.png`, `componentes-proyector.png` | Los componentes base, en `/muestrario` |
| `aviso-vencimiento.png` | El aviso de que la sesión está por vencer |
| `sesion-vencida.png` | La vuelta al ingreso cuando el token vence |
| `pantalla-no-cargo.png` | La barrera de errores: el archivo de una pantalla ya no está en el servidor y se ofrece recargar, con la barra a la vista |
